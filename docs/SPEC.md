# 模拟考场（Mock Exam Clock）— 产品与数据规格

一个「虚拟考场时钟 + 模块计时 + 成绩分析」的 iOS 应用。考生可以在任何真实时间，进入一场
「设定时间」（如 09:00–11:00）的模拟考试：界面显示的就是考场的表，而不是手机上的真实时间。

本文档是 Web（PWA）与 SwiftUI 原生两个实现的共同依据，两端的字段名、取值、算法必须一致。

---

## 1. 核心概念

| 概念 | 说明 |
| --- | --- |
| 模块模版 Template | 一组有序的模块（如 图推 / 判断推理 / 资料分析 / 言语理解 / 数量关系），每个模块可填「满分」，可不填 |
| 模拟考试 Session | 一次考试：计划开始/结束时间、选用的模版、总分（可选）、实际开始时刻、模块计时记录、得分 |
| 虚拟时钟 Virtual clock | 考试中显示的「考场时间」。从 `开始时间` 起，按真实 1:1 速度前进，不受真实时钟影响 |
| 模块计时 | 当前模块从进入时开始计时，按「完成本模块」记一次用时，并进入下一个模块 |

关键时间语义：

- `plan.startVirtual` / `plan.endVirtual`：一天内的毫秒偏移（0 … 86,399,999）；若 `endVirtual <= startVirtual`，
  视为跨零点，`durationMs = endVirtual - startVirtual + 24h`。
- 考试开始后，`virtualNow = startVirtual + (realNow - startedAt)`，**必须用时间戳差值计算**，不能用定时器累加，
  这样切后台、锁屏、刷新页面都不会漂移。
- `virtualNow >= startVirtual + durationMs` 即「考试结束」→ 自动收卷（`finishReason = "timeup"`）。
- 模块用时 `elapsedMs = endedAt - startedAt`（真实时间戳差）。

## 2. 数据模型（持久化 JSON，两端同构）

存储位置：Web 用 `localStorage["mock-exam:v1"]`；iOS 用 `Application Support/mockexam.json`。
首次启动写入默认数据（含一个示例模版「行测（示例）」）。

```jsonc
{
  "version": 1,
  "settings": {
    "clockMode": "digital",      // "digital" | "analog"
    "sound": true,               // 结束/完成提示音
    "keepAwake": true,           // 考试中保持屏幕常亮
    "lastSetup": {               // 新建考试时预填
      "startVirtual": 32400000,  // 09:00:00
      "endVirtual": 39600000,    // 11:00:00
      "moduleCount": 4,          // 选「默认模块」时的模块个数 2…8
      "templateId": null,
      "totalScore": null
    }
  },
  "templates": [
    {
      "id": "tpl_1",
      "name": "行测（示例）",
      "modules": [
        { "id": "tmod_1", "name": "常识判断", "maxScore": null },
        { "id": "tmod_2", "name": "判断推理", "maxScore": 30 }
      ],
      "createdAt": 1730000000000,
      "updatedAt": 1730000000000
    }
  ],
  "sessions": [
    {
      "id": "ses_1",
      "name": "国考行测 模拟",           // 用户可空 → 前端显示「模拟考试」
      "templateId": "tpl_1",             // null 表示用的是「默认模块一/二/…」
      "templateName": "行测（示例）",     // 快照，模版之后被改/删不影响历史
      "plan": {
        "startVirtual": 32400000,
        "endVirtual": 39600000,
        "durationMs": 7200000,
        "totalScore": 100                // null = 未设置总分
      },
      "modules": [
        {
          "id": "sm_1",
          "name": "常识判断",
          "maxScore": null,              // 来自模版，可空
          "score": null,                 // 用户后填，可空
          "startedAt": 1730000000000,    // 真实时间戳
          "endedAt": 1730000600000,
          "elapsedMs": 600000,
          "skipped": false               // 保留字段，当前恒为 false
        }
      ],
      "status": "running",               // "running" | "finished" | "discarded"
      "startedAt": 1730000000000,        // 点「开始考试」的真实时刻
      "finishedAt": null,
      "finishReason": null,              // "manual" | "timeup" | null
      "totalScore": null,                // 用户后填的总得分
      "note": "",
      "scoresFilled": false              // 是否已录入得分（任一分数字段非空即 true）
    }
  ]
}
```

约定：

- 所有 id 由端内生成（`前缀_随机串`），不依赖外部服务。
- 删除模版不修改已产生的 session（session 内已快照模块名/满分）。
- 金额/分数一律 number | null，空字符串视为 null。

## 3. 功能与界面

### 3.1 首页

- 顶部品牌区：`模拟考场`，副标题 `把任何时间，变成考场上的那两个小时`。
- 「快速开始」大按钮（进入新建考试）。
- 上次设置摘要：`09:00 – 11:00 · 120 分钟 · 行测（示例）`。
- 入口：模块模版（n 个）、考试记录（n 次）。
- 若存在 `status == "running"` 的 session：首页顶部显示「有一场考试未结束 · 继续」（悬浮卡片）。

### 3.2 新建考试（底部弹层 / Sheet）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 考试名称 | 文本，可空 | 占位符「例：2026 国考行测 第 3 套」 |
| 开始时间 | 时间选择 00:00–23:59 | 默认 09:00 |
| 结束时间 | 时间选择 | 默认 11:00；自动显示「共 120 分钟」；支持跨零点 |
| 模块模版 | 列表选择 | 「默认模块（4 个）」（个数可调 2–8）/ 自定义模版 / `+ 新建模版` |
| 考试总分 | 数字，可空 | 占位符「选填，如 100」 |

校验：`durationMs > 0`（结束=开始视为 24h，允许）。点击「开始考试」进入考试页。

### 3.3 考试中（全屏，无底部导航）

- 状态条：`● 考试进行中`（呼吸红点）+ 真实时间小字 `现在 15:32`。
- 时钟主体：
  - 数字模式：`HH:MM:SS` 超大等宽数字，下方 `考试时间 09:00 – 11:00`。
  - 表盘模式（可切换）：SVG 模拟表盘（12 刻度 + 时针/分针/秒针），考场挂钟风格。
  - 两者都显示 `剩余 HH:MM:SS`，最后 5 分钟变红并轻微闪烁；`已用 xx 分钟`。
  - 进度条：已用 / 总时长。
- 模块区：
  - 当前模块卡片：名称、`本模块 12:34`、按钮 `完成本模块 →`（主按钮）、`撤销上一个`（有记录时才可用）。
  - 模块列表：编号 + 名称 + 已完成用时 / 进行中 / 待开始。
  - 完成最后一个模块 → 弹窗「全部模块已完成，现在交卷？」→ 交卷。
- 底部：`提前交卷`（次要）、`放弃本场`（危险，二次确认后 status = discarded，不进记录）。
- 到达 `endVirtual` 时：播放提示音、全屏提示「考试结束」→ 自动收卷，未完成的模块不计时，
  弹窗展示「考试结束 · 时间到」并进入结果页。
- 屏幕常亮（Wake Lock），退出（切后台）时停止，回前台重新申请。
- 刷新/杀进程回来后：若存在 running session，恢复现场（时钟按时间戳重算；若已超时则直接收卷）。

### 3.4 结果与分析

概览卡：

- `实际完成总用时`（各模块用时之和，若模块覆盖率不足会标注）
- `考试耗时`（开始到收卷的真实时长）
- `提前 12:30 交卷` 或 `超时 03:00`
- 总分 `78 / 100`（仅当 plan.totalScore 与 session.totalScore 都有值时）+ 得分率；
  只填了得分未填总分：显示 `78 分`。
- 各模块得分合计与总得分不一致时提示「模块得分合计 75 ≠ 总得分 78」。

用时分布：横向堆叠条 + 模块图例；每个模块一行「名称 / 用时 / 占比」条形。

模块明细表（列按数据可用性显示）：

| 模块 | 用时 | 用时占比 | 得分 | 满分 | 得分率 | 效率 |
| --- | --- | --- | --- | --- | --- | --- |

效率判定（同时有得分与用时）：

- `scoreShare / timeShare >= 1.15` → `优势`（产出高）
- `0.85 … 1.15` → `均衡`
- `< 0.85` → `低效`（耗时长、得分少）

仅有用时：`timeShare >= 0.30` → `重头`，`<= 0.10` → `轻量`。

自动分析文字（3–5 条，按重要性排序）：

1. 用时最多的模块与其占比、绝对用时；
2. 若录入得分：得分率最高/最低的模块；
3. 若同时有得分与用时：指出「用时占比 - 得分占比 > 10 个百分点」的模块，给出压缩建议
   （建议压缩为其用时的 `timeShare → scoreShare` 换算值，取整到分钟，最少 3 分钟）；
4. 若超时/提前：给出剩余时间利用建议；
5. 未录入得分时提示「补录得分后可看到投入产出分析」。

操作：`编辑得分`（同 3.4 顶部表单：总得分 + 各模块得分 + 备注）、`复制分析文本`、`删除记录`。

### 3.5 模块模版

- 列表：名称、模块数、模块名预览、`编辑` `删除`。
- 编辑页：名称；模块行（`名称` 输入 + `满分(选填)` + 上移/下移/删除）；`+ 添加模块`；保存。
- 至少 1 个模块；名称去空格、不允许全空（否则拒绝保存并提示）。

### 3.6 考试记录

- 倒序卡片：名称、日期时间、状态（已完成/已放弃）、总用时、得分（若有）。
- 点开进入分析页；左滑/长按删除（Web 用按钮）。

## 4. 交互与视觉

- 深色为主（考场感）：背景 `#0B0F14`，面板 `#141A21`，主色 `#3DDC97`（考场绿），
  结束/警告 `#FF5C5C`，文字 `#E8EEF5` / `#8A98A8`。
- 数字用等宽字体（`ui-monospace, "SF Mono", Menlo`），时钟字号随视口自适应（`clamp()`）。
- 模块配色（图表）：`#3DDC97 #4AA8FF #FFC857 #B983FF #FF7A9C #5CE1E6 #F5A623 #93A7BA`。
- 所有按钮最小 44×44 pt 点击区；主按钮全宽；危险操作用红色文字 + 二次确认。
- 支持 `prefers-color-scheme: light`：浅色为纸张白 + 墨色数字（考场日光灯感）。
- 竖屏优先，允许横屏；考试页在横屏时上下布局。
- 中文界面，不依赖网络（离线可用）。

---

## 5. 非功能

- **零依赖**：Web 用原生 ES Module，无构建步骤；iOS 只用系统框架。
- **离线**：Service Worker 预缓存全部静态资源。
- **无后端、无账号**：数据只在本机。
- **数据导出**：Web 支持导出/导入 JSON 备份；iOS 支持分享 JSON（或至少 Files 可见）。
- **性能**：时钟刷新 1 次/秒（`requestAnimationFrame` 或 250ms interval 均可），不得整页重绘。

## 6. 验收用例

1. 任意时刻新建 09:00–11:00 考试并开始 → 时钟从 09:00:00 走，剩余 02:00:00 递减；真实时间只作小字显示。
2. 完成 3 个模块 → 模块用时之和 = 三个模块用时相加；撤销一个 → 回到上一模块且其计时应清零重算。
3. 把系统时间往真实时间 +10 分钟，回到页面 → 虚拟时钟同步前进 10 分钟（基于时间戳）。
4. 考试到 11:00:00 → 自动结束并提示，记录 finishReason=timeup。
5. 填总分 100、模块满分 30/30/40，得分 25/18/30 → 分析页显示总分 73/100（得分率 73%）、
   各模块得分率、效率标签与建议；若只填总分不填模块分 → 只展示总分与得分率，不展示效率标签。
6. 模版改名/删除后，历史记录仍显示旧模块名与满分。
7. 09:00–11:00 的计划时长显示为 120 分钟；23:00–01:00 显示 120 分钟。
8. 刷新页面（考试中）→ 弹出「继续未完成的考试」，点击后时钟、模块进度一致。
