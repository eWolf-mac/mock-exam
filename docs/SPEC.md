# 模拟考场（Mock Exam Clock）— 产品与数据规格 v2

一个「虚拟考场时钟 + 模块计时 + 成绩分析」的 App。考生可以在任何真实时间，进入一场「设定时间」
（如 09:00–11:00）的模拟考试：界面显示的就是考场的表，而不是手机上的真实时间。

本文档是 Web（PWA）与 SwiftUI 两个实现的共同依据。**当前 Web 端已实现 v2；iOS 端仍是 v1，待同步。**

v2 相对 v1 的变化：

1. 模块支持**二级模块**，子模块逐个计时，用时汇总到一级模块；
2. 新增**考试模版**（可预设考试名称、起止时间、模块模版、总分）；
3. 模块可设**题目数 / 每题分值**，分析页按**正确题数**折算得分（每题分值缺省 1 分）；
4. 模块可设**建议用时**，考试中提示剩余/超出，分析里对比实际用时。

---

## 1. 核心概念

| 概念 | 说明 |
| --- | --- |
| 模块模版 Template | 一组有序模块 + 每个模块的二级模块、题目数、每题分值、建议用时、满分（都可空） |
| 考试模版 ExamTemplate | 一场考试的预设：名称、默认起止时间、默认模块模版（或默认模块数量）、默认总分 |
| 模拟考试 Session | 一次考试：计划起止时间、快照下来的模块结构、实际计时记录、正确题数与得分 |
| 虚拟时钟 | 从 `开始时间` 起按真实 1:1 前进，不受真实时钟影响 |
| 计时步骤 Step | 有子模块时每个子模块是一步；没有子模块时模块自身是一步 |

时间语义：

- `startVirtual` / `endVirtual`：一天内的毫秒偏移；`endVirtual <= startVirtual` 视为跨零点。
- `virtualNow = startVirtual + (now - startedAt)`，**必须用时间戳差值**，切后台/刷新都不漂移。
- 一级模块若有子模块：`elapsedMs = Σ 子模块 elapsedMs`，父模块不单独计时。
- `finishedAt` 之后虚拟时钟停在 `plan.endVirtual`（收卷时刻）。

## 3. 功能与界面

### 3.1 首页
品牌区、快速开始、上次设置摘要；`模块模版` / `考试模版` / `考试记录` 三个入口；
未结束的考试显示「继续」卡片；偏好设置（提示音、常亮、导入导出备份）。

### 3.2 新建考试
- 顶部**考试模版**选择（没有模版时不显示）：选中即带入名称/起止时间/模块模版/总分，仍可手改。
- 字段：考试名称（选填）、开始时间、结束时间（自动算时长，支持跨零点）、模块模版（默认模块可调 2–8 个）、考试总分（选填）。

### 3.3 考试中
- 数字 / 表盘时钟、剩余时间、进度条、真实时间小字；最后 5 分钟变红。
- 当前步骤卡片：
  - 无子模块：`当前模块 2/5` + 模块名 + 计时 + `建议 35:00 · 还剩 12:00`（超出变红）。
  - 有子模块：`模块 2/5 · 子模块 2/4` + 子模块名 + 子模块计时 + 子模块建议用时，上方一行 `本模块合计 12:34 / 建议 35:00`。
  - 按钮文案随之变成「完成子模块 →」。
- 模块列表：已完成打 ✓ 显示用时，进行中高亮，二级模块缩进显示（`2.1 图形推理`）。
- 「撤销上一个」：回退到上一段（子模块优先），该段用时清零重新计时。
- 最后一个步骤完成 → 询问交卷；也可随时「提前交卷 / 放弃本场」。
- 到点自动收卷（提示音 + 全屏结果页提示）。
- **建议用时提醒**：当前步骤剩余 5 分钟时响一次、超出建议用时再响一次（每段各一次，`settings.suggestWarn` 可关）。

### 3.4 结果与分析
- 概览：实际完成总用时（Σ 模块）、考试耗时、提前/超时/压线、统计总分（手填优先，否则各模块合计，并标注「各模块合计」）。
- 用时分布：堆叠条 + 每模块条形；有建议用时的显示 `建议 xx / 超 xx` 或 `省 xx`；有子模块的列出子模块用时与占比。
- 模块明细表：模块 / 用时（含每题平均）/ 较建议（±）/ 得分（含满分与得分率）/ 效率；子模块作为缩进行。
- 得分录入：
  - 有题目数的模块 → 填**正确题数**，得分 = 正确题数 × 每题分值（缺省 1）；
  - 没有题目数 → 直接填**模块得分**；
  - 总得分可填可不填，不填按模块合计；填了以手填为准并在不一致时提示。
- 自动分析 3–5 条：用时最多、超建议用时、**平均每题快慢**、得分率高低、投入产出最差/最好、提前或超时、数据缺漏提示。
- 复制分析文本（含子模块）、**生成长图**（750px 宽，含分数/用时/模块/分析）、删除记录。

### 3.7 趋势
记录页右上角进入，最多 12 场：
- **成绩**：只统计有统计总分的考试，折线 + 数值标签；
- **用时**：统计实际完成总用时（分钟）；
- 下方给出场次 / 平均 / 最好 / 最近，以及最近 8 场的列表。

### 3.5 模版
「模块模版 / 考试模版」分段切换。
- 模块模版编辑器：每个模块一张卡 —— 名称、建议用时、题目数、每题分值、满分（选填）、二级模块列表（名称 + 建议用时）、上移/下移/删除。
- 考试模版编辑器：名称、默认开始/结束时间、默认模块模版或模块数量、默认总分。

### 3.6 记录
倒序卡片：名称、时间、模版、状态；右侧显示得分（有分）或总用时；点开看分析。

## 4. 计分规则（优先级从高到低）

```
模块每题分  = perQuestionScore ?? 1
模块满分    = maxScore ?? (questionCount ? questionCount × 每题分 : null)
模块得分    = score ?? (correctCount != null && questionCount != null ? correctCount × 每题分 : null)
统计总分    = totalScore（手填） ?? Σ模块得分（仅当所有模块都有得分时才算）
得分率      = 统计总分 / plan.totalScore（两者都有值才算）
```

分析里的「效率」标签：所有模块都有得分且合计 > 0 时，比较「得分占比」与「用时占比」：

- `得分占比 / 用时占比 ≥ 1.15` → 优势
- `0.85 … 1.15` → 均衡
- `< 0.85` → 低效

没有得分时按用时占比：`≥30%` 重头、`≤10%` 轻量、其余一般；用时为 0 → 未开始。

## 5. 验收用例

1. 任意时刻建 09:00–11:00 考试 → 时钟从 09:00:00 走，剩余 02:00:00 递减。
2. 模块含 2 个子模块：依次完成后，父模块用时 = 两段之和；撤销最后一个子模块 → 父模块用时回滚、后续模块回到未开始。
3. 考试中刷新页面 / 杀进程回来 → 恢复现场，时钟按时间戳重算。
4. 到 11:00:00 自动收卷，记录 `finishReason = timeup`。
5. 模版设 40 题、每题 0.8 分、正确 30 题 → 得分 24，满分 32，得分率 75%。
6. 只设题目数不设每题分、正确 15/20 → 得分 15、满分 20（每题按 1 分）。
7. 各模块得分合计 79、手填总分 82 → 统计总分 82，并提示两者不一致。
8. 模块建议 30 分钟、实际 34:10 → 分析里 `超 04:10`，并出现超时建议。
9. 考试模版「行测上午场 08:30–10:30，满分 100」→ 新建考试选中后时间/总分/模块自动带出。
10. 模版改名或删除后，历史记录仍显示旧模块名、题目数、子模块。
11. v1 备份导入后自动补 `children: []`、`questionCount: null` 等字段，旧得分（score）保持可用。
