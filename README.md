# 模拟考场（Mock Exam Clock）

一个「虚拟考场时钟 + 模块计时 + 成绩分析」的 App：在任意真实时间，把时钟拨到考试的
09:00–11:00，像在考场一样做题、按模块计时，交卷后看用时与得分分析。

| 目录 | 实现 | 状态 |
| --- | --- | --- |
| `web/` | **PWA**（原生 ES Module，零依赖、零构建），iPhone Safari 可添加到主屏幕、可离线 | **v2，唯一在维护的版本** |
| `ios/` | SwiftUI 原生 Xcode 工程（iOS 17+） | **v1 存档**：未同步 v2、未编译验证，详见 [ios/README.md](ios/README.md) |
| `docs/` | 产品与数据规格、部署说明、UI 截图 | — |

需求与数据模型见 [`docs/SPEC.md`](docs/SPEC.md)；上线部署见 [`docs/DEPLOY-GITHUB-PAGES.md`](docs/DEPLOY-GITHUB-PAGES.md)。

## 最近新增

**v2**

1. **二级模块**：模块下面可挂子模块，考试时逐个子模块计时，用时自动汇总到一级模块；
2. **考试模版**：预设考试名称、默认起止时间、默认模块模版、默认总分，新建考试一键带出；
3. **题目数与每题分值**：模版里填「题目数 / 每题分值」，交卷后只填**正确题数**即可自动算分
   （每题分值不填按 1 分）；总分 = 各模块合计，**手填总分优先**；
4. **建议用时**：每个模块（和子模块）可设建议用时，考试中提示「还剩 / 已超出」，分析里对比实际用时。

**v2.1**

5. **建议用时提醒**：某一段剩 5 分钟、以及超出建议用时时各响一次提示音（设置里可关）；
6. **多次模考趋势**：记录页右上角「趋势」，成绩 / 用时两条折线，最多 12 场，带平均与最好成绩；
7. **长图分享**：分析页「生成长图」，把分数、模块用时、得分和分析画成一张图，
   iOS 走系统分享面板，其它环境自动下载；
8. **每题平均耗时**：有题目数的模块显示「46 秒/题」，分析里还会比较最快 / 最慢的模块。

**v2.2**

9. **删除考试记录**：记录页「管理」模式下可逐条删除、**按考试模版删除**、**删除全部**，三种都带确认警告；
10. **趋势按考试分组**：顶部 chip 按考试模版/模块模版分组，只看某一场考试的走势；
11. **二级模块也能设题目数与每题分**：每题分留空就继承一级模块（可单独覆盖）；
12. **二级模块单独录分**：有二级模块时，录入拆到每个二级模块（正确题数或得分），一级模块显示合计与满分。

**v2.3**

13. **模块数可直接输入**：不再是加减到 8 个，改成数字输入（1–99），加减按钮保留；
14. **按题计时（逐题模式）**：新建考试时切到「按题计时」，输入题目数 → 自动生成 `第1题…第N题`，
    每题单独计时，考试总用时 = 各题之和；题多时模块列表变成**答题卡网格**；
15. **逐题分析**：平均每题用时、每题用时柱状图（带平均线、最慢题高亮）、最慢 / 最快 5 题。

**v2.4**

16. **每题明细**：点柱状图的柱子看该题用时；「全部题目」进明细页（总用时/平均/中位数，按题号或按用时排序，
    点行展开开始/结束时刻与排名）；
17. **逐题文案重写**：不再出现「建议用时/模块得分率」，改成平均每题、最慢最快、超均值题数、前/后半程配速；
18. **考试模版带结构**：模版可设「按模块」或「按题计时」的默认结构，两种参数都保留；新建考试默认用上次的结构；
19. **趋势分组更细**：逐题 + 考试模版 → `模版名 · N 题`；逐题 + 自定义 → `逐题 · N 题`；模块模式照旧；
20. **逐题满分**：不填总分时自动按「每题 1 分 × 题数」，填了得分就能看到得分率；
21. 修复：从记录页进入考试详情后，返回会跳回首页（现在回到记录页/趋势页来源）。

## 1. 立刻用起来（Web / PWA）

```bash
node tools/serve.mjs 8123        # 启动本地静态服务（默认目录 web/）
```

- 电脑浏览器 <http://localhost:8123/>
- **手机访问**：手机与电脑同一 Wi-Fi，打开 `http://<电脑局域网IP>:8123/`（启动时会打印地址）
- **装到桌面**：iPhone Safari → 分享 → 添加到主屏幕，之后全屏、无地址栏

> ⚠️ 局域网 http 地址在 iOS 上**无法注册 Service Worker**，关掉电脑上的服务就打不开了。
> 想真正离线使用，必须部署到 HTTPS（见下）。

### 1.1 部署到 GitHub Pages（推荐）

仓库里已备好 [`.github/workflows/pages.yml`](.github/workflows/pages.yml)：推送到 `main` 后只发布 `web/`
目录。得到 `https://<用户名>.github.io/<仓库名>/` 后，手机打开一次即完成离线缓存，之后断网可用。

完整步骤（含两种方案、更新流程、数据迁移、常见问题）见
[`docs/DEPLOY-GITHUB-PAGES.md`](docs/DEPLOY-GITHUB-PAGES.md)。

### 常用命令

## 2. 功能

### 2.1 虚拟考场时钟
- 设定开始/结束时间，点「开始考试」后时钟从 09:00 走起，与手机真实时间无关；右上角小字显示真实时间。
- 数字时钟 / 表盘时钟（SVG 挂钟）两种；剩余时间、已用时间、进度条；最后 5 分钟变红；到点响铃自动收卷。
- 支持跨零点（23:00–01:00 = 120 分钟）；考试中保持屏幕常亮；切后台回来按时间戳重算；杀进程可恢复。

### 2.2 模块与二级模块计时
- 开考前选模块模版，或不选（自动生成「模块一…」，2–8 个）。
- 一级模块可挂二级模块：考试时逐个子模块计时，父模块用时 = 子模块之和。
- 「完成本模块 / 完成子模块」记时并自动进入下一段；「撤销上一个」回退并清零重计。
- 每个模块/子模块可设建议用时，超时提示变红。

### 2.3 模版
- **模块模版**：模块名、建议用时、题目数、每题分值、满分（选填）、二级模块列表；可排序、增删。
  二级模块同样能设题目数、每题分（留空继承一级）、建议用时。
- **考试模版**：名称、默认起止时间、默认模块模版（或模块数量）、默认总分。新建考试时一键套用，仍可手改。

### 2.4 考试分析
- 实际完成总用时、考试耗时、提前/超时/压线、统计总分与得分率。
- 用时分布（含子模块占比）、模块明细（用时 / 每题平均 / 较建议 ± / 得分 / 效率）。
- 得分录入：有题目数填正确题数自动算分，否则直接填模块得分；
  有二级模块时**按二级模块逐个录分**，一级模块实时显示「合计 / 满分」；总分不填按合计、填了以手填为准。
- 自动分析 3–5 条：用时最多、超建议、平均每题快慢、得分率高低、性价比最低/最高、提前或超时。
- 复制文本报告、**生成长图**、删除记录、导出/导入 JSON 备份。

### 2.5 建议用时提醒
考试中每段剩 5 分钟响一次提示音、超出建议用时再响一次（每段各一次，设置里可关）。

### 2.6 趋势
记录页右上角进「趋势」：先按**考试分组**（chip：全部 / 某场考试模版），再切成绩或用时折线
（最多 12 场），带场次、平均、最好、最近四项统计。

### 2.7 删除记录
记录页「管理」：逐条删除、按考试模版删除（独立页面，按分组列出条数）、删除全部（二次确认）。
三种都会提示「无法恢复，建议先导出备份」。

### 2.8 数据
全部只存本机（Web `localStorage`），无账号无后端；旧版本数据打开时自动升级（当前 v3）。

## 5. 已知限制

- **iOS 原生版是 v1 存档**：功能停在 v1、从未用 Xcode 编译验证；项目目前只维护 PWA。
- Web 版在 iOS 上不能震动，到点提醒靠提示音 + 界面高亮。
- 完全离线需要 HTTPS（GitHub Pages 即可）。
- 分数只接受非负数；正确题数超过题目数只做软提示，不强制。
